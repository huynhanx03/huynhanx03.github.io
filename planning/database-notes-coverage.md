# Database notes coverage map

This map assigns the four topic tracks to their source material. It is a planning map, not proof that every subject is already taught in depth. See [the chapter audit](./database-book-audit.md) for current depth and concrete gaps. Notes are original teaching material in Vietnamese and English, not transcriptions of the books. Version-sensitive behavior is checked against official product documentation.

## Topics and reading order

1. `database-systems` — Hệ thống cơ sở dữ liệu / Database Systems
2. `mysql-design-performance-operations` — MySQL — Thiết kế, tối ưu và vận hành / MySQL — Design, Optimization & Operations
3. `postgresql-transactions-queries-storage` — PostgreSQL — Giao dịch, truy vấn và lưu trữ / PostgreSQL — Transactions, Queries & Storage
4. `redis-data-structures-applications` — Redis — Cấu trúc dữ liệu và ứng dụng thực tế / Redis — Data Structures & Real-World Applications
